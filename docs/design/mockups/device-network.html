添加设备：这台设备和新设备是什么关系？

对等设备 · 我的另一台设备

这台⇄新设备

加入你的身份：共享设备名单和模型订阅。只用于你自己、信任的设备。

受控设备 · Worker

这台→新设备

这台设备可以在新设备上执行任务；新设备不能访问你的任何设备。适合不信任的执行节点。

访客 · 别人的设备

新设备→这台

新设备只能使用这台设备上你允许的功能；这台设备不能访问它。

新设备上核对时看到的说明（与邀请方相反的视角）

加入「MacBook Pro」所在的身份

MacBook Pro⇄这台

这台设备会成为对等设备，共享设备名单和模型订阅。只在两台都是你的设备时确认。

让「MacBook Pro」控制这台设备

MacBook Pro→这台

确认后，MacBook Pro 可以在这台设备上执行命令、打开终端、管理项目。这台设备不能访问 MacBook Pro。

成为「MacBook Pro」的访客

这台→MacBook Pro

这台设备可以使用 MacBook Pro 允许的功能；MacBook Pro 不能访问这台设备。
