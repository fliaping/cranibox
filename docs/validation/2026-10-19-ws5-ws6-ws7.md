## 已实现

### WS5：六个 Agent

- 统一注册表：DeepSeek Harness、Codex、Claude Code、Pi、Hermes、OpenClaw。安装发现、模型配置、无头启动、会话发现及 MCP 配置消费同一注册表；默认值统一为 DSH。
- DSH 固定为 0.1.1-rc.2；npm tarball SHA-256 为 47ec05f45ada5ab87779ae18a90456b5ebff5421dc0ff5c179677d65e1c16057。安装失败时不继续，日志打印版本与摘要。升级方法见插件 README。
- 模型配置的首次原文备份、私有修改日志、漂移检查、精确键撤销；覆盖六套 golden、用户修改后撤销及逐字节恢复。DSH 的 Cordis 序列格式和 YAML 注释保留；OpenClaw 当前直接编辑原生配置文件并清理受管缓存项，尚未按任务书优先调用 `openclaw config set`。
- Pi 使用原生模型配置与本项目的 stdio MCP 扩展，覆盖初始化、工具发现/调用、取消和关闭。六个 Agent 均能注册 MCP；单独删除一个 MCP 不会删除其他 MCP 或模型配置。
- 设备/待审批列表 MCP、Computer MCP、已启用时的 Browser MCP 自动登记。待审批 MCP 只读，不能代表人做审批决定。
- DSH、Pi、Claude Code 原生工具审批写入同一私有队列，经 App 卡片决定后继续；拒绝、过期、撤销、重复决定有测试。Codex、Hermes、OpenClaw 的原生审批桥接尚未实现，能力标记如实返回 false。

### WS6：名册、Vault 与接管

- Owner 签名名册、固定 Owner 指纹、递增 epoch、成员/Hub/Claude 节点约束与 Owner 密钥 HPKE 分发辅助接口。
- SQLite Vault、XChaCha20-Poly1305 密文、HPKE DEK 包装、平台钥匙串及无头环境私有文件回退。Claude 凭据不进入同步数据。
- 逐节点启用及未来节点自动启用、签名记录合并、OAuth generation/lease epoch 冲突处理、刷新合并、租约续期/接管/交还、停用持有者、撤销成员时轮换 DEK。
- 现有 TCP + Noise 上的真实 llm / vault 子路由，权限与名册联合校验；访客被拒绝。按本机、Hub、home、priority 选路；首字节前故障重试及健康恢复防抖。
- 本机代理持续使用 127.0.0.1:3424；已同步且在本机启用的账号可在 Hub 下线后继续使用。Claude 节点离线返回专用错误。
- 三节点 Noise 集成测试，以及三独立进程测试/可选 Linux netns 抓包脚本。测试使用独立身份、预配置签名名册和假 key，不依赖真实配对。

### WS7：个人 Agent 界面

- 浏览器与 Tauri 共用 React 个人界面及 App API：五栏主导航、首次引导、审批卡、五种状态标签、模型与订阅表单、逐节点开关、设备卡、任务抽屉、中英双语、明暗主题及窄屏布局。

## 尚未完成的集成与人工验收

这些限制不能算作三份任务书全部验收通过：

1. **真实扫码/SAS 配对及 OwnerKey 交付**：WS1 已随 PR #17 合入 main，本分支后续也已合并其代码；仍需把配对后端接入 App、名册及 OwnerKey 交付。现有真实多节点测试预先配置可信关系。iroh 场景同样尚未执行，当前完成的是 Noise 路径。
2. **远程 DSH 对话切换**：当前首页只嵌入本机 DSH；远程选项禁用。DSH 安装状态也尚未结合 Web 服务健康检查，未运行服务时不能视为对话就绪。
3. **其余三个 Agent 的原生审批**：Codex、Hermes、OpenClaw 尚未接入卡片。六种卡片能渲染不等于六类真实事件源全部接通；配对、能力、Computer Use、模型写操作的专用事件与决定路径仍需联调。
4. **真实网络故障注入**：需要执行 netns 抓包，并补充网络分区/延迟、Hub 重启回切和流式中断端到端验收。当前有对应状态机/租约测试，不代表整条真实部署链路已经验证。
5. **真实厂商账号与原生桌面**：需协调者按任务书使用真实账号验收；本次没有读取或使用真实厂商凭据。Pi MCP 的完整真实 CLI 工具回合和各桌面系统通知/托盘交互也需要补验。
